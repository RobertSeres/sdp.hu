# SDP.hu Rebuild - Google Antigravity Edition

This is a modern, futuristic rebuild of the SDP.hu website using React, Tailwind CSS, and Framer Motion.

## Prerequisites

- Node.js (v18 or higher)
- npm (comes with Node.js)

## Setup Instructions

Since the environment where this code was generated lacked Node.js, you need to install dependencies manually:

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Project Structure

- `src/components`: UI and Layout components
- `src/pages`: Page components (Home)
- `src/data`: Content data (keeping text separate from code)
- `src/lib`: Utilities (Tailwind merger)

## Features

- **Glassmorphism Design**: Using backdrop-blur and semi-transparent backgrounds.
- **Physics Animations**: Floating elements and smooth entrance animations using Framer Motion.
- **Responsive**: Fully responsive grid layouts for all devices.
- **Content**: All original content from SDP.hu preserved and structured.
